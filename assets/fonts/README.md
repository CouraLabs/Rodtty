# Bundled fonts

Geist and Geist Mono faces come from [vercel/geist-font](https://github.com/vercel/geist-font), revision `ef2597cfc42f4797676df105517ccc0a1cfa6569`, under the SIL Open Font License in [Geist-OFL.txt](Geist-OFL.txt). The unmodified regular, medium, semibold, italic and semibold italic TTF files provide Rodtty's default interface and code/terminal families without installation. Other Unicode scripts and emoji use the host's font fallback; terminal glyph origins remain on the terminal cell grid.

The retained IBM Plex Mono face is covered by [IBMPlexMono-LICENSE.txt](IBMPlexMono-LICENSE.txt).
