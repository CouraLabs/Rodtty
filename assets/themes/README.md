# Appearance palette sources

Catppuccin Latte and Mocha colors and all sixteen ANSI entries are copied from
[Catppuccin palette v1.8.0](https://github.com/catppuccin/palette/blob/main/palette.json),
Git blob `2a5d25cb0b00033bb049d11ab12c8bed478bf4e8` (tree
`07d02aa110ef9eb7e7427afca5c73ba9cf7f8ebd`). Full permission and copyright notice:
[Catppuccin-LICENSE.txt](Catppuccin-LICENSE.txt).

Rodtty maps the canonical base/mantle/surface/text/accent colors onto shared
semantic roles. Editor and Git diff syntax colors derive from these same roles
through Rune Kit's SyntaxTheme, and diff tints use the palette's green/red/blue.
Extended indexed terminal colors (16–255) and explicit truecolor output retain
their requested RGB values in either appearance.
